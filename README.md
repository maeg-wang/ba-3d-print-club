# 北京中学3D打印社团

一个面向学校 3D 打印社团的展示与服务网站，提供社团介绍、作品展示、打印登记入口等功能，帮助同学们更方便地了解社团活动、浏览优秀 3D 打印作品，并提交自己的模型进行打印预约。

> 让每一位同学都能接触并掌握 3D 打印技术，将创意从屏幕带进现实。

---

## 项目简介

本项目是我们学校 3D 打印社团的官方网站，主要用于：

- 展示社团介绍、设备资源和开放时间；
- 展示社团成员的优秀 3D 打印作品；
- 提供 3D 打印登记说明；
- 宣传社团活动、建模教学与技术分享。

网站整体风格简洁清晰，适配桌面端和移动端浏览。

## 社团信息
- 社团名称：学校 3D 打印社团
- 网站主题：3D 打印社团 - 创意无限
- 适用对象：全校学生
- 主要用途：社团展示、作品展示、打印登记

## 开放时间

周一至周五：`16:30 - 20:00`

> 周末开放时间以社团公告为准。

## 作品展示
展示社团成员的优秀 3D 打印作品，包括：

- 作品名称；
- 作者；
- 打印时长；
- 使用材料；
- 作品缩略图或展示图。

## 打印登记
提供 3D 打印登记说明，帮助同学们了解提交模型的要求和流程。

## 社团服务

我们提供以下社团服务：
- 拓竹打印机免费使用；
- 拓竹H2C，适用于高精度模型；
- 建模软件教学，如 Fusion 360、Blender；
- 模型分析与打印参数优化指导；
- 常用材料提供，如 PLA、PETG、树脂；
